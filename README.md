# Family Games

Track shared board-game matches and scores with family members. 7 Wonders matches store seven score categories; other games store one point value. Backed by Supabase.

| Folder | App |
|---|---|
| [`flutter/`](flutter) | Flutter app (Android, iOS). See [flutter/README.md](flutter/README.md). |
| [`swift/`](swift) | Native SwiftUI port for iOS 26 with the Liquid Glass design. See [swift/README.md](swift/README.md). |

Both apps use the same Supabase project and `fg_*` schema (source of truth: [danny270793/supabase](https://github.com/danny270793/supabase)).
